# learn-about-compilers
Goal: To learn more about compilers and how they work, like what the process is for breaking down code into assembly or bytecode.

i.e lexing -> parsing -> type checking -> IR -> code gen

Also a good chance to practice more with Rust, C#, and haskell (I did go a little crazy with the languages)

Following various tutorials and guides for how things work code etc. (for my own reference)

This is being written on an arch linux vm and so currently was designed with linux in mind. With that this will currently only work on x86_64 based linux machines. This is primarily due to the ASM generation and the elf file generation using linux specific os information to generate

Current functionality:
  - Can break down and compile simple math expressions:
    - Adding
      - EX: 7 + 5 
    - Subtracting (Cannot handle negative numbers)
      - EX: 4 - 1
    - Multiplication (Can only handle basic multiplication of small numbers)
      - EX: 2 * 2
  - Running this code will generate 2 files output_a and output_b
      - _a is the asmebly code broken down into its op code bytes
        - will need to chmod +x the file to allow for execution
        -  Currently doesnt write out to standard out it instead exits will the value as the error code so after running
              the file execute a echo $? to see the value
      - _b is the generated byte code
        - this file can only be run by the deserializer method in the go code and will print out the answer
