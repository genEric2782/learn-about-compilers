# learn-about-compilers
Goal: To learn more about compilers and how they work, like what the process is for breaking down code into assembly or bytecode.

i.e lexing -> parsing -> type checking -> IR -> code gen

Also a good chance to practice more with Rust, C#, and haskell (I did go a little crazy with the languages)

Following various tutorials and guides for how things work code etc. (for my own reference)
List so Far:
- https://mohitkarekar.com/posts/pl/lexer/
- https://www.youtube.com/watch?v=GAU51Dqsp3Y&list=PLI1h1vRqlHLNZAa2BEM9uZ2GEvUNYDasO <-- inital architecture and overview, my lexer is based around this 
- https://www.youtube.com/watch?v=mNOLaw-_Buc
- https://wiki.osdev.org/X86-64_Instruction_Encoding#REX_prefix <-- some basics about encoding for the elf generation

This is being written on an arch linux vm and so currently will not work for windows (specifically things like the elf code generation)
